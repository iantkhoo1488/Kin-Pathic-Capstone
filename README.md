# Kin-Pathic-Capstone
Capstone for heartrate monitor 

All the different iterations and versions of the code for the NRF52DK prototype

| Version | Files Changed | Changes / Improvements |
|---------|--------------|------------------------|
| v1 | All files (initial) | Initial project creation. Basic MAX30102 driver with zero-crossing HR algorithm. Simple BLE Heart Rate Service using `BT_LE_ADV_CONN_NAME` macro. Old devicetree overlay using `sda-pin`/`scl-pin` syntax. |
| v2 | overlay | Fixed devicetree overlay for NCS v2.x+. Replaced deprecated `sda-pin`/`scl-pin` with pinctrl syntax using `NRF_PSEL` macros. Added `i2c0_default` and `i2c0_sleep` pinctrl states. Removed deprecated `label` property from MAX30102 node. |
| v3 | prj.conf | Fixed Kconfig parse errors. Removed inline comments from `CONFIG_BT_DEVICE_APPEARANCE` and `CONFIG_LOG_DEFAULT_LEVEL` — Kconfig does not allow inline comments on integer values. Added `CONFIG_PINCTRL=y`. |
| v4 | ble_hrs.c | Fixed `BT_LE_ADV_CONN_NAME` undefined error. Replaced deprecated macro with explicit `bt_le_adv_param` struct using `BT_LE_ADV_OPT_CONNECTABLE`. Added separate `sd[]` scan response array carrying device name. |
| v5 | ble_hrs.c | Fixed `BT_LE_ADV_OPT_CONNECTABLE` undefined error (also renamed in NCS v3.x). Replaced with `BT_LE_ADV_OPT_CONN`. Added forward declaration for `start_advertising()`. Moved device name into `ad[]` array. |
| v6 *(first working version)* | All files | Full audit and rewrite for NCS v3.2.4. Replaced `bt_conn_cb_register()` with `BT_CONN_CB_DEFINE` macro. Removed deprecated `label` properties. Fixed all inline Kconfig comments. Removed VLA in HR algorithm — replaced with static buffer and running `prev` variable to avoid stack issues on embedded target. |
| v7 | max30102.c, max30102.h, main.c | Major algorithm upgrade. HR algorithm replaced with Pan-Tompkins inspired pipeline: DC removal → derivative → squaring → moving-window integration → adaptive threshold peak detection → mean inter-peak BPM. Added signal quality check (AC/DC ratio / perfusion index proxy). Added finger presence detection via IR threshold. Added 5-reading BLE smoothing buffer with spike rejection (20 bpm threshold). Added sliding window — keeps last 50% of samples between calculations. Rate-limited BLE notifications to every 3 seconds. Added 4x hardware FIFO averaging reducing effective rate to 25 sps. |
| v8 | prj.conf | Attempted fix for BLE Error 133 (GATT error on connect). Added `BT_BUF_ACL_RX/TX_SIZE=251`, `BT_L2CAP_TX_BUF_COUNT=6`, `BT_CONN_TX_MAX=6`. Added `BT_GATT_SERVICE_CHANGED`, `BT_SETTINGS`, `FLASH`, `FLASH_MAP`, `NVS` for bonding persistence. Disabled `BT_PRIVACY` to fix nRF Connect app re-pairing issues. |
| v9 | prj.conf, ble_hrs.c | Root fix for Error 133. Stripped flash/NVS/settings stack (was causing boot fault). Disabled `BT_SMP` — no pairing needed for HRM. Added MTU exchange request immediately on connect via `bt_gatt_exchange_mtu()` in `on_connected()` callback — the primary fix for Android/iOS dropping connection during GATT discovery. |
| v10 | prj.conf | Fixed linker error: undefined reference to `bt_gatt_exchange_mtu`. Added `CONFIG_BT_GATT_CLIENT=y` — this symbol lives in the GATT client subsystem and is required even when used from a peripheral. |
| v11 | main.c | Fixed one-shot update issue. Removed sliding window (was mixing stale data). Removed BLE rate limiter (`BLE_NOTIFY_INTERVAL`). Buffer now resets fully to zero after every calculation window. BLE notified on every valid result. |
| v12 | main.c | Fixed FIFO polling race condition. Replaced single-sample polling every 40ms with full FIFO drain loop every 200ms. Inner loop reads until `got==0` (FIFO empty). Collects all pending samples in batch rather than risking timing drift with one-at-a-time reads. |
| v13 | max30102.c, max30102.h, main.c | Root fix for unreliable FIFO reads. New `max30102_drain_fifo()` reads `WR_PTR`, `OVF_COUNTER` and `RD_PTR` in a single I2C burst transaction to eliminate race condition between separate pointer reads. Calculates available samples with correct circular wrap at 32. Reads all samples in one second burst. Poll interval increased to 500ms. main.c updated to call `drain_fifo()` instead of `read_sample()`. |
| v14 | max30102.c, max30102.h, main.c | Removed all finger detection and signal quality gating. No more finger threshold check, quality check, spike rejection, or smoothing history. Algorithm always runs and always sends a result. Simplified main loop: drain FIFO every 500ms, fill buffer, run algorithm, send result, reset. |
| v15 | main.c, ble_hrs.c, ble_hrs.h | Added onboard LED status indicators. LED1 (P0.17): solid on at boot as power indicator. LED2 (P0.18): blinks at 1Hz while advertising/waiting for connection. LED3 (P0.19): solid on when BLE central is connected. LED4 (P0.20): flashes 80ms on each successful BLE notification. LED2/LED3 managed by background `ble_blink_thread`. Added `bt_hrs_is_connected()` to ble_hrs API. Used deprecated `device_get_binding()` — fixed in v16. |
| v16 *(current)* | main.c | Fixed LEDs not turning on. Replaced deprecated `device_get_binding("GPIO_0")` with `GPIO_DT_SPEC_GET` using `DT_ALIAS(led0..led3)`. Uses nRF52-DK board DTS aliases which correctly define active-low polarity. `GPIO_OUTPUT_INACTIVE` handles active-low inversion automatically without manual bit flipping. |
